# Политическая география

Сайт учебной дисциплины: восемь семинаров, методика, артефакты и литература. Одна визуальная система на все страницы — печатный атлас: бумага, тушь, один сигнальный цвет, карты как основной носитель структуры. Карты построены своим кодом по Natural Earth 110m, без внешних тайлов, библиотек и картинок.

## Сборка

Нужен Node.js 20 или новее. Зависимостей нет, `npm install` не требуется.

```sh
node build.mjs
```

Команда полностью пересобирает `site/`: 15 HTML-страниц, стили, скрипт, шрифты, иконку, `sitemap.xml` и `robots.txt`. Исходники лежат в `src/`, тексты и числа — в `content.json`, геометрия суши — в `assets/data/ne_110m_land.geojson`. Тексты страниц берутся из `content.json` без правок.

Локальный просмотр:

```sh
python -m http.server 8000 --directory site
```

Открывать `http://127.0.0.1:8000/`. Маршруты — каталоги (`/course/`, `/seminars/01-djibouti/`), поэтому они одинаково работают и в локальном сервере, и на Vercel. Ссылки абсолютные, сайт рассчитан на корень домена: через `file://` стили не загрузятся.

## Структура

```
build.mjs                 генератор страниц
content.json              единственный источник текстов и чисел
src/map.mjs               проекция Робинсона, кадры карт, миниатюры
src/styles.css            визуальная система
src/app.js                фильтр, связь карты и указателя, раскрытия
assets/data/              Natural Earth 110m land, public domain
assets/fonts/             Literata, Golos Text, IBM Plex Mono, woff2
site/                     готовый статический сайт
vercel.json               настройки статического деплоя
```

Маршруты: `/`, `/course/`, `/seminars/`, восемь `/seminars/<slug>/`, `/method/`, `/artifacts/`, `/reading/`. Плюс `404.html`.

### Карты

Одна проекция Робинсона на весь сайт. Мировая карта задаёт порядок восьми кейсов; на каждом семинаре — кадр той же проекции, приведённый к формату 4:3: короткая сторона открывается, а если это увеличило бы кадр больше чем вдвое, длинная сторона подрезается вокруг точки съёмки. Восьмой семинар («Весь корпус») показан мировой картой: его координаты в данных — «Сводная схема». Миниатюры в карточках — те же кадры, упрощённые и вынесенные в SVG-спрайт страницы.

У первого семинара в `content.json` рамка записана с перепутанными широтой и долготой (`bbox: [-6, 30, 62, 54]`, точка — 43.1° E, 11.6° N). Сборщик определяет это по точке съёмки, меняет значения местами и печатает предупреждение. Сами данные не правятся.

## Деплой

Vercel не собирает сайт: `buildCommand` пустой, `outputDirectory` указывает на готовый `site/`.

```sh
vercel deploy --prod --yes --project political-geography-v2 --scope kirin-jindoshs-projects
```

```json
{
  "framework": null,
  "buildCommand": "",

  "trailingSlash": true

```

Алиас `political-geography.vercel.app` принадлежит текущему проду и этим проектом не меняется.

## Что проверено

- 15 страниц собираются одной командой; 319 внутренних ссылок ведут на существующие файлы; внешних ссылок 60, все взяты из `content.json`.
- Горизонтального переполнения нет: 14 маршрутов × 320, 390, 768, 1440 px, `scrollWidth === clientWidth` во всех 56 случаях.
- Читаемый текст в `main` не меньше 16 px на 320 и 390 px; служебные mono-подписи мельче осознанно.
- Мера строки основного текста на 1440 px — 61–75 знаков с пробелами (замер по символам, последняя строка отброшена).
- Контраст текста к фону не ниже 4.5:1 (3:1 для крупного) — проверено обходом всех текстовых узлов на 390 и 1440 px.
- Шрифты self-hosted, кириллические сабсеты, `font-display: swap`, системный фолбэк; `document.fonts.check` подтверждает загрузку Literata, Golos Text и IBM Plex Mono.
- Фильтр форматов: 8 карточек, 9 чипов; выбор «Симуляция» оставляет 1, «Все» возвращает 8. Без JS список читается целиком.
- Раскрывающиеся ответы: 4 блока на семинар, первый открыт, остальные раскрываются по клику.
- Все восемь точек на мировой карте; наведение на точку и на строку указателя подсвечивает пару и меняет строку под картой.
- Тексты, поля и источники сверены с `content.json` программно; ни одна строка не переписана.

## Слабые места

- Внутренние ссылки абсолютные: сайт не открывается через `file://` и не переносится в подпапку без правки ссылок.
- Кадры семинаров 4 и 8 шире остальных по содержанию: у первого рамка охватывает три континента, у восьмого карта мировая. Это следует из данных и решения о «сводной схеме».
- Проверено в Chromium (Chrome и Edge). Firefox и Safari вживую не гонялись.
- Витрина артефактов пустая по требованию: восемь слотов без вымышленных работ. У двух источников нет ссылки, стоит «в библиотеке».
